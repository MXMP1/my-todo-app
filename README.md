# ToDo List: менеджер задач с локальным хранилищем

Простой и удобный менеджер задач с поддержкой тёмной/светлой темы, фильтрацией выполненных задач и экспортом/импортом данных. Проект создан на базе Vue.js и Vite.

## Описание

Веб‑приложение для управления личными или рабочими задачами. Позволяет добавлять, редактировать, отмечать выполненные задачи, а также экспортировать и импортировать их в формате JSON. Все данные сохраняются в `localStorage`, поэтому они сохраняются между сессиями браузера.

## Основные функции

* **Добавление новых задач:** ввод названия задачи и нажатие Enter.
* **Отметка выполнения:** переключатель (toggle) для отметки задачи как выполненной.
* **Фильтрация:** кнопка‑переключатель для скрытия/показа выполненных задач.
* **Смена темы:** переключение между светлой и тёмной темой интерфейса.
* **Экспорт задач:** сохранение всех задач в файл `.json` на компьютер.
* **Импорт задач:** загрузка задач из файла `.json` (перезаписывает текущий список).
* **Локальное хранилище:** все задачи автоматически сохраняются в `localStorage`.
